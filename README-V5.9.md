# JARVIS V5.9 — Cinematic Boot

Cinematic JARVIS startup inspired by the supplied reference: dark technical console, central rotating core, diagnostics, personal network scan, synchronized original hard-rock boot soundtrack and JARVIS voice sequence.

## Audio
`jarvis-boot-audio.mp3` is an original generated hard-rock/technical boot track with an original synthetic male English voice. It is **not** the AC/DC recording. If Pepe has a licensed audio file he wants to use privately, it can replace this file without changing the boot code.

## Browser audio
The first `ACTIVATE JARVIS` tap starts the audio directly inside the user gesture to maximize compatibility with Samsung Internet autoplay rules. Subsequent automatic boots attempt playback, but browser policy can still require a tap.
