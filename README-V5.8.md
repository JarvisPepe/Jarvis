# JARVIS V5.8 – Cinematic Boot

V5.8 upgrades the startup experience with a cinematic cyan HUD boot sequence inspired by sci-fi system interfaces: scan beam, HUD frame, rotating core, staged system diagnostics, progress bar and a welcome transition.

Audio remains browser-native for now. V5.8 prefers an available English male voice and lowers pitch/rate; it also adds a short system boot tone. A fully custom JARVIS-style voice would require a separately generated/licensed audio asset or TTS provider and is not copied from the referenced YouTube video.

First launch requires **ACTIVATE JARVIS** because mobile browsers restrict autoplay audio. Later launches attempt the sequence automatically.
