# JARVIS HUD V5.6.1

Mobile-first Samsung PWA HUD.

## Neu in V5.6.1
- Source Health für Kalender, Wetter, Kids, Sports, Fantasy, Tippspiele und PUPIL.
- Snapshot-Daten werden niemals als LIVE dargestellt.
- Status: LIVE / STALE / ERROR / PENDING / NOT CONNECTED / PUBLIC ONLY.
- Live Gateway bleibt optional und wird über `JARVIS_CONFIG.liveEndpoint` konfiguriert.
- Keine Credentials oder API-Keys im HUD.

## Installation
Der HUD benötigt für eine echte PWA-Installation eine HTTPS-Adresse. ZIP lokal entpacken reicht zum Testen, aber nicht für die normale Samsung-Internet-PWA-Installation.
